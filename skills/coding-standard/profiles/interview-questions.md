# Profile：面试深挖（interview-questions）

仅在面试深挖 Profile 开启时由 `SKILL.md` 加载并执行。默认关闭。

代码生成/修改完成后、自检通过并交付后，必须基于本次改动生成一份「面试深挖」面经。面经内容涵盖本次代码所涉及技术栈在中大厂面试中可能被问到的高频问题及标准答案，帮助开发者将日常开发沉淀为面试竞争力。

## 开启条件

1. 项目根目录存在 `.coding-standard.yaml` 且 `interview-questions: true`
2. 或用户口头要求开启（如「按 coding-standard 开启面试深挖」「生成面经」「面试深挖」）
3. 满足任一条件 → Read 加载本文件并执行
4. 否则 → **不加载**，不生成面经

```yaml
# 项目根目录 .coding-standard.yaml
interview-questions: true
```

## 面经生成时机

- 在代码自检全部通过、向用户交付最终代码之后
- 生成面经作为交付的一部分紧随其后
- 若本次改动极小（如单行注释修正、变量重命名），可声明跳过并说明原因

## 面经结构

生成的面试题按以下顺序组织，每个部分必须包含「问题」和「参考答案」：

### 一、技术基础高频题（对应一面/笔试）

从本次代码涉及的技术点出发，挖掘大厂一面或笔试中的高频基础问题。

**出题来源参考**：华为、腾讯、阿里、快手、京东、字节、美团等中大厂真实面经

**出题方向**：

| 本次涉及的技术点 | 可能被问的方向 |
|-----------------|---------------|
| Java 语言特性（Lambda/Stream/Optional/泛型/注解等） | 原理、使用场景、坑点、源码级理解 |
| Spring 全家桶（Boot/Cloud/MVC/Security/Data） | 自动配置、AOP/IoC、事务传播、过滤器与拦截器区别 |
| MyBatis / JPA 等持久层 | SQL 注入防护、缓存机制、懒加载、N+1 问题 |
| Vue / React 前端框架 | 响应式原理、虚拟 DOM、diff 算法、生命周期 |
| TypeScript 类型系统 | 泛型约束、条件类型、类型体操、类型推导边界 |
| 数据库（MySQL/Redis/ES等） | 索引优化、事务隔离级别、缓存穿透/击穿/雪崩 |
| 网络与协议（HTTP/HTTPS/WebSocket/RPC等） | 握手过程、安全机制、协议选型 |
| 并发与线程安全 | synchronized/Lock、线程池、volatile、CAS |

### 二、深度原理与源码题（对应二面/三面）

基于本次代码中用到的框架/中间件/设计模式，追问底层原理和实现细节。

**出题要点**：
- 追问「为什么这么设计」「源码怎么实现的」
- 追问底层数据结构、算法思想
- 追问异常边界和极端场景下的行为

### 三、系统设计与架构题（对应三面/交叉面）

从本次改动的功能域出发，延伸出相关系统设计问题。

**出题要点**：
- 如何从零设计一个类似的系统/模块
- 高并发、高可用、数据一致性方面的考量
- 技术选型的权衡与对比

### 四、场景题（重点★）

模拟面试官给出一个与本次代码相关的实际业务场景，考察候选人的分析思路和解决方案。

**场景题格式**：
1. **场景描述**：面试官口述的场景（含隐含的矛盾或坑）
2. **考点分析**：点出面试官真正想考察的能力点
3. **参考答案**：分步骤的回答思路

**场景题命题技巧**：
- 场景必须合理，不能凭空编造
- 通常包含一个「两难」或「坑」——比如改动会影响现有功能、性能与代码整洁的矛盾
- 参考答案要有层次：先复述理解 → 再拆解分析 → 最后给出方案和理由

## 出题数量建议

| 本次改动规模 | 建议出题量 |
|-------------|-----------|
| 小幅改动（单文件、单方法级） | 3-5 题，覆盖 1-2 个板块 |
| 中等改动（多文件、一个功能模块） | 6-10 题，覆盖 3-4 个板块 |
| 大幅改动（多模块、架构级变更） | 10-15 题，全覆盖 |

## 出题原则

1. **紧扣本次代码**：每一道题都必须能从本次改动的代码中找到落点——为什么这道题会被触发
2. **真实可考**：题目应来自真实面试经验，不要编造偏门/冷门的理论题
3. **答案有深度**：参考答案不能只是概念定义，要有代码示例、实战经验、对比分析
4. **场景题是核心**：每个面经至少包含 1 道场景题，且场景要与业务紧密相关
5. **简要申明**：生成面经前简短声明「正在生成面试深挖面经...」
